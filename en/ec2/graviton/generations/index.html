Graviton 7th / 8th / 9th gen, and what each generation improved

Gen 7 = Graviton3 (M7g, C7g, R7g), Gen 8 = Graviton4 (M8g, C8g, R8g, X8g, I8g), Gen 9 = Graviton5 (M9g, C9g, R9g). Based only on public AWS sources, compiled 2026-11.

Bottom line
7th genbrought Graviton into the DDR5 and SVE era;8th genscaled things up: 96 cores per chip, double the L2, and 3x the vCPUs and memory of the 7th generation at the largest size;Gen 9Puts 192 cores intoA singlechip, L3 grows 5×, memory moves to DDR5-8800, the clock reaches 3.3 GHz, and it is the first to use the formally verified Nitro Isolation Engine. By AWS's numbers, each generation is about 25–30% faster than the last.

2 · 7th gen → 8th gen: Go large-scale

  • 1.5x cores, 3x size: From 64 to 96 cores per chip; the largest size uses two chips for 192 vCPUs. The largest R8g size has 3x the vCPUs and memory of R7g, and X8g goes up to 3 TiB of memory [4][9].
  • L2 doubled: From 1 MB to 2 MB per core, with each vCPU getting its own dedicated cache [1][4].
  • Memory goes from 8 channels to 12 channels, at up to DDR5-5600; the network- and storage-enhanced variants (M8gn / M8gb) go up to DDR5-6400 [4].
  • Armv9 + SVE2: Adds SVE2 and a set of integer, bf16 and crypto vector instructions. Note that vector width changes from Graviton3's 2×256 bit to 4×128 bit [1].
  • Clock speed 2.6 → 2.8 GHz, still no Turbo, so performance is stable and predictable [1].
  • Performance: Up to 30% faster than Graviton3; X8g is up to 60% faster than X2gd [4][9].
  • New top-end model: M8gn uses 6th-generation Nitro cards with up to 600 Gbps of networking; M8gb offers up to 300 Gbps of EBS bandwidth and 1,440K IOPS [4].

3 · 8th gen → Gen 9: 192 cores on a single chip

  • 192 cores on a single chip: Gen 8 needs two chips combined to reach 192 vCPUs; Gen 9 does it with one [1][2].
  • L3 is 5× the previous generation, with up to 33% lower core-to-core latency [2].
  • Memory DDR5-8800(Gen 8 is 5600), which AWS calls the fastest memory in the cloud; it is also the first in the AWS fleet to support PCIe Gen6 's CPU [2][3].
  • Clock speed 2.8 → 3.3 GHz, with the core design upgraded from Neoverse V2 to V3 and the ISA to Armv9.2-A [1].
  • Network and EBS bandwidth: 15% / 20% higher on average across sizes, doubled at the largest size (48xlarge): 100 Gbps networking, 72 Gbps EBS; up to 3x packet processing performance [2][3][5].
  • Instance Bandwidth Configuration (IBC): Shift up to 25% of bandwidth allocation between EBS and networking [2].
  • Local disk: M9gd has up to 11.4 TB of NVMe, with 30% higher IOPS than M8gd [2].
  • Energy efficiency: AWS calls Graviton5 the most energy-efficient processor it has ever built [5].

How to read these numbers
All published by AWS "at most" gains, measured under different test conditions, so they can't be added together or converted into one another. Always run A/B load tests on your own workload; to judge whether the CPU is really saturated, see this series' Telling when resources are maxed out on ARM.

Gen 9 currently only has M / C / R and their local-disk variants (gd). There are no network- or EBS-optimized variants like M8gn or M8gb yet. So if you needLimitnetwork or EBS bandwidth, the 8th-gen gn / gb variants are currently higher [3][4][5].

6 · Safety

  • 7th gen: Memory is always encrypted (always-on memory encryption), with support for Pointer Authentication (PAC) [1][6].
  • 8th gen: Adds Branch Target Identification (BTI), and each vCPU gets its own dedicated cache [1][4].
  • Gen 9: First introduced Nitro Isolation Engine. It handles isolation between VMs (including access to VM memory, CPU registers and I/O devices), and usesFormal verificationMathematically proves that the isolation holds; AWS says this makes Nitro the first formally verified cloud hypervisor [2][5].

7 · Time to market

  • Gen 8: C8g and M8g became generally available in 2024-09 [8]; R8g, X8g, I8g and the gd / gn / gb variants followed, and as of 2025-12 Regions are still being added [10].
  • Gen 9: M9g preview announced at re:Invent in 2025-12 [7] → 2026-06 M9g / M9gd and C9g / C9gd generally available [2][3] → 2026-08 R9g / R9gd generally available [5] → From 2026-09, rolling out to more Regions (e.g., C9g in Tokyo); Lambda Managed Instances also start supporting Graviton5 [11][12].

Gen 7 launch dates aren't listed here: this page only cites sources checked against the original.

8 · What to watch for when upgrading

7th gen → 8th gen

  • Compiler flags -mcpu=neoverse-512tvb Applies to all three generations; usuallyNo recompilation needed [1].
  • 32-bit userspace no longer supported: Also, armv7 / 32-bit programs must first be replaced with 64-bit versions [1].
  • Vectors go from 2×256 bit SVE to 4×128 bit: SVE code tuned specifically for 256 bit needs to be re-benchmarked.
  • 48xlarge is two chips and two NUMA nodes, so pay attention to NUMA; see NUMA deep-dive guide.

8th gen → 9th gen

  • The instruction set is backward compatible, so code usually just runs; several customer cases got gains with "zero code changes" [2].
  • Memory-bandwidth-sensitive workloads (databases, caches, analytics) benefit most from DDR5-8800 and the larger L3.
  • 16xlarge and 48xlarge still have 2 NUMA nodes, so large sizes still need NUMA pinning [1].
  • If you need maximum network or EBS bandwidth, the 8th-gen gn / gb models currently go higher. First confirm that 9th gen is available in your Region.

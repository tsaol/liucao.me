两条车道 · θ 慢环 与 Σ 快环
covers slides 18–20
整个 field 用一个公式概括：Aₜ₊₁ = IMPROVE(A₁:ₜ ; Sₜ)。 Agent 由权重 θ 和脚手架 Σ 组成 · 改哪个决定循环的节奏和风险。 2026 共识：先 Σ 后 θ —— Σ 先探索验证，稳定策略再蒸馏进 θ。
θ参数慢环 · 改权重
自蒸馏 · 自奖励 RL · RLVR · TTT — 能力真正内化
  • 内生生成示范 Dₜ · 内生评价 eₜ · 外生轨迹 τₜ
  • 高成本 · 有灾难性遗忘风险
  • 典型代表：SPICE · Self-play SWE-RL · AAR
慢 · 贵 · 不可逆
Σ脚手架快环 · 改代码
prompt · memory · tools · full scaffold — 透明可逆
  • Prompt · Memory · Tools · Full Scaffold（自改代码）
  • 低延迟 · 有结构漂移风险
  • 典型代表：DGM · Meta-Harness · AHE · ShinkaEvolve
快 · 便宜 · 可回滚
本次分享的实验 + Demo 只动 Σ 侧 · 不改一个模型参数
🔁 术语补丁 · RSI 是什么 Recursive Self-Improvement · 递归自我改进
RSI = AI 一代一代改自己 · 改完再拿改进版继续改。Recursive（递归）= 结果反过来当输入；Self（自我）= 改的是自己不是别的东西；Improvement（改进）= 每轮理论上更好。这是本次分享所有方法（DGM · AlphaEvolve · ShinkaEvolve）的共同数学骨架。
Aₜ₊₁ = IMPROVE(A₁:ₜ ; Sₜ)
A = agent 配置（θ 权重 + Σ 脚手架）· S = 改进信号（示范 / 评价 / 探索经验）

评测哲学 · Delta Attribution
covers slides 25–26
涨的分不是白涨的。每一分要拆三块 —— T 借的（额外算力）· O 租的（评测捷径）· G 挣的（真改进）。 只有 G 才是可迁移、可上线的收益。
T · 借的
O · 租的
G · 挣的
T · 额外计算：预算匹配基线后消失
O · 评测捷径：离开该评测就崩
G · 挣的：跨模型/跨集仍然涨
Harvey 实验对应关系：成本罚 → 管 T · 泄漏审计 → 管 O · 跨模型迁移 → 验 G
  • MLS-Bench 的三个约束 — 收益必须可归因、跨 ≥3 评价设置成立、放大规模仍保序
  • Live Demo 的对应设计 — 综合分构成条把 T/O/G 显式画出来（公开测验 / hold-out / 抗干扰 / 代码惩罚）
  • 最扎心的一句 — "改进机制是否值得信任 比 分数涨没涨 更难"

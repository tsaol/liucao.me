② 核心概念,一句话版

  • RSI(递归自我改进):AI 改进它自己,再用改好的版本继续改自己。判断标准:改进的对象是不是系统自己。
  • 哥德尔机 vs 达尔文哥德尔机:前者「先证明有益才改」(像律师),后者「先试再选」(像育种的农民)。
  • harness:包在模型外面的那一层 —— prompt、代码、工具、检索逻辑。本场只改 harness,模型权重冻结(模型 = 厨师,harness = 菜谱和厨房)。
  • 一轮进化:选亲本 → 变异 → 评测 → 晋升门 → 存回档案库。好的坏的都存,差的版本可能是「踏脚石」。
  • 钱花在哪:一轮约 $856,其中 97.7% 是评测。改菜谱 5 分钟,但每个新菜谱都要请 200 个客人试吃。
  • 结论:能自我改进 ≠ 能自我验证。运动员可以自己练,不能自己当裁判。

③ 常见问题

「候选 agent 跑评测」和「LLM 评审 judge」分别是什么?

候选 agent 跑评测 = 考试。每轮改出来的新版本 harness 就是「候选」,它要把测试集里的每道题真的做一遍:读题、调工具、思考、重试,每一步都调大模型。估算一轮 72 次 run × 3.77M token ≈ 2.7 亿 token,按 Bedrock 上 Sonnet 5 的价格约 $836。

LLM 评审 judge = 改卷。没有标准答案的题,另请一个大模型读 agent 的最终答案并打分。它只读最终答案、只写一个分数,所以便宜(约 $12)。有标准答案的题(比如 demo 里的 NDCG@5)可以不用 judge。

NDCG@5 是什么?

给「搜索结果排得好不好」打分,0 到 1,1 是完美。三点:结果越相关得分越高;排得越靠前越值钱(按 log₂(名次+1) 打折);最后除以「完美排法」的得分。@5 = 只看前 5 条。

一句话版:看前 5 条结果里,对的东西是不是排在最前面。demo 里 BM25 0.42 → LLM 重排 0.94,就是对的商品基本都被排到了最前面。

晋升门的「综合得分」怎么算?

demo 代码(evolution/evaluate.py)里的实际公式:

综合得分 = 0.7 × 公开题得分
        + 0.2 × 隐藏题 NDCG      ← 从不给模型看,防背答案
        + 0.1 × 错别字题 NDCG    ← 换个说法再考,防死记
        − 0.005 × 估算 token(百万) ← 成本罚,防靠多花钱刷分

公开题得分 = 0.3 × 简单 + 0.4 × 中等 + 0.3 × 难 × (简单、中等是否达标)
泄漏审计发现偷写答案 → 直接 −1,作废

像期末总评:平时作业 70% + 闭卷考试 20% + 换题重考 10% − 迟到扣分;抄袭直接零分。成本罚系数很小,demo 里几乎不影响结果。

UBC 是什么公司?

不是公司,是加拿大不列颠哥伦比亚大学(University of British Columbia,温哥华)。DGM 由东京的 AI 公司 Sakana AI 和 UBC Jeff Clune 的实验室合作完成。

为什么不直接改模型权重?

改权重要训练(SageMaker 那一侧),贵、慢,验证更难,也很难回滚;改 harness 只跑推理(Bedrock),便宜,随时能换回来。用厨师的话说:换菜谱随时能换回来,送厨师去进修可退不回来。

⑤ 国内研究成果

论文的单位和摘要已在 arXiv 原文第一页核对。标 二手 的数字来自新闻、项目页或公众号,没有读到原文实验表。

1. Harness / agent 自进化 和本场最接近

  • 上海 AI Lab · Self-Harness 2606.09498 2026-06
    弱点挖掘 → 提出改动 → 回归测试通过才接受。Terminal-Bench 2.0 隐藏题:MiniMax M2.5 40.5% → 61.9%,Qwen3.5-35B-A3B 23.8% → 38.1%,GLM-5 42.9% → 57.1%。

    测模型能不能自己搭 harness、再自己进化。结论偏冷静:有提升但不稳定,迁移到新任务有限。同项目 Self-Developing Agents 还说:自我评判几乎预测不了下一轮提升,宣称的最终版本只有 2/9 在隐藏题上真的最好 二手
  • 华为 · HarnessEvolve 2609.00829 2026-09
    参考轨迹找错因;质量门(防泄露、防提示词膨胀)+ 性能门;最后用 held-out 选版本 —— 和本场的「晋升门」几乎一样。

  • SE-Agent 2508.02085(清华、阶跃星辰、北大、中科院等):SWE-bench Verified 上 Claude-3.7-Sonnet 40.6% → 61.2% 二手
